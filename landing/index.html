Cómo funciona

Habla. Escucha. Sigue jugando.

Todo pasa en segundos y sin cambiar de ventana: el overlay se queda encima del juego sin quitarle el foco.

1

Mantén Ctrl+Win

Graba tu voz y toma una captura de la pantalla donde estás jugando.

2

Whisper transcribe

En tu propia GPU, gratis y privado. Si el juego la ocupa, la CPU entra de respaldo.

3

Claude piensa

Opus responde rápido y, si la pregunta es difícil, se toma más tiempo. Solo mira la pantalla si hace falta.

4

Te lo dice

Escuchas la respuesta mientras sigues jugando, y las acciones se ejecutan solas.

Instalar

Listo en dos minutos

Clona el repo, instala las dependencias y ábrelo. Queda en la bandeja del sistema, siempre a mano.

# Requiere Python 3.11+ y Claude Code con sesión iniciada
git clone https://github.com/farriagadal/desk-ai.git
cd desk-ai
pip install -r requirements.txt
pythonw app.py

Necesitas Windows 10/11, una suscripción de Claude con Claude Code y, idealmente, una GPU NVIDIA.

Preguntas

Preguntas frecuentes

¿Es gratis?

Desk AI es gratis y de código abierto (MIT). Usa tu suscripción de Claude a través de Claude Code, así que no pagas API ni necesitas claves.

¿Qué pasa con mi privacidad?

Tu voz se transcribe en tu PC con Whisper. A Claude solo llega el texto de tu pregunta y, si la necesita, la captura de pantalla. La ventana de Desk AI se excluye de sus propias capturas.

¿Afecta el rendimiento del juego?

Whisper usa poca memoria de video (int8) y, si el juego acapara la GPU, la transcripción pasa a la CPU automáticamente. El overlay nunca le quita el foco al juego.

¿Funciona sin GPU NVIDIA?

Sí, con un modelo de Whisper en la CPU. Es más lento, pero funciona.

¿En qué idiomas está?

Por ahora en español. Las contribuciones para otros idiomas son bienvenidas en GitHub.
